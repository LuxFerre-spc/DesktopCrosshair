桌面准星
========
双击同文件夹内的「桌面准星.exe」即可运行，无需安装和管理员权限。

功能
• 十字、T 型、圆形，调整实时生效。
• 厚度 0–20 像素，中心间距 -100–100 像素，长度 0–150 像素。
  滑条、数字输入和微调箭头都支持 0.1 数值步进。
  默认清晰模式使用完全不透明的实体像素：0 隐藏，大于 0 最细显示为 1 像素，几何尺寸吸附到像素网格。
  如需通过半透明像素模拟小于 1 像素的宽度，可勾选「亚像素平滑」。这会让细线显得更淡。
• 厚度设为 0 时完全隐藏线条和线条描边，仍可独立显示中心点。
• 中心间距表示相对两臂的总间距，负数让两臂向中心内交叉穿过。T 型没有上臂。
• 中心点有独立开关，大小为 0.1–20 像素，可只留中心点。
  四臂长度统一取整后镜像生成；中心点、圆环和取样区域共用同一交点。
  清晰模式按物理像素对称绘制，极小的中心点尺寸会栅格化到能够保持对称的像素集合。
• 「不透明度 %」可设为 0–100，100 为完全不透明，0 为全透明，支持 0.1% 微调。
  整个准星（线条、中心点和描边）统一生效；该设置与亚像素平滑独立。
  低于 100% 时最终显示色会与背景混合，核对互补色建议先用 100%。
• 圆形半径 = max(0, 中心间距 ÷ 2 + 长度)；厚度控制圆环线宽。
  半径为 0 或长度为 0 时不画圆环。
• 固定颜色：用颜色选择器或输入 #RRGGBB 后点击「应用」。
• 自动配色：取四臂理论交点周围一小块区域的平均颜色。
  默认「彩色高对比」：优先选择相反色相，并独立调整明暗，保持高饱和度和明显的颜色。
  它会选择与取样颜色对比至少为 3:1 的彩色；这表示原始实色对比，不包括降低不透明度后的混色效果。
  中性灰背景使用黄色或洋红色；深棕背景会得到明亮蓝青色，避免旧互补色保持暗色而看不清。
  也可选择「黑白高对比」，在黑与白中选对比更强的一种。保留「对比描边」更容易辨认复杂背景上的准星。
  默认 3×3，可选 1×1、3×3、5×5、7×7 或 9×9；整条准星统一使用该互补色。
  取样区域随交点一起移动；交点落在半像素位置时对边界像素加权，避免采样中心偏移。
  设置面板显示「交点小块平均 #xxxxxx → 准星 #xxxxxx」，便于确认实际取色和配色。
  为补偿明暗，彩色模式会调整亮度，不再使用 1.0.0 的纯色相旋转规则。
  约每 65 毫秒更新，只在颜色或参数变化时重绘。
  Windows 截屏排除机制用于避免取到准星本身；不可用时状态栏会提示并使用固定颜色。
• 可选黑白描边，改善中性灰背景下互补色对比不足的问题。
• 一键居中：回到当前目标中心，并清零 X/Y 偏移。跟随 CS 时目标为游戏画面区域，其他时候为所选显示器。
• 进入 CS 自动居中默认开启。识别前台 cs2.exe / csgo.exe 的窗口客户区，排除标题栏与边框。
  约每 65 毫秒检查一次实际区域；改变分辨率、移动窗口或换屏后自动重新居中。
  切回本工具设置时保持游戏目标，切换到其他软件或游戏最小化后使用所选显示器。
  X/Y 偏移依然生效；需要精确中心时点击「一键居中」将偏移清零。
• 多显示器选择，X/Y 可精确调整位置，坐标单位为物理像素。
• 准星置顶、不抢焦点、鼠标点击穿透。

快捷键
三项快捷键默认均为空白，不占用任何按键。
点击对应输入框后按需要的按键或组合键即可绑定。
支持 Ctrl、Alt、Shift 组合；退格、Delete 或「清除」按钮取消绑定。
Esc 取消本次输入。若快捷键被占用，会提示，保留原绑定。
支持「显示/隐藏」「居中准星」「打开设置」。

收起与退出
「收起到托盘」或最小化后设置窗口隐藏，准星继续工作。
双击系统托盘图标重新打开，也可右键托盘操作。
默认点击设置窗口的关闭按钮会询问「退出程序」或「最小化到托盘」，也可取消。
勾选弹窗中的「以后不再询问，记住本次选择」后，会按本次选择直接执行。
设置面板底部可随时修改「点击关闭按钮时询问」及「不询问时」的默认行为。
托盘菜单里的「退出」直接彻底退出，准星随之消失。
再次启动会自动读取上次设置。
配置位置：%LOCALAPPDATA%\DesktopCrosshair\settings.xml

性能
自动配色和游戏定位仍按约 65 毫秒周期响应。
取色缓冲区重复使用，静止预览不重绘，图像按实际准星尺寸分配。
设置面板的文字最多每 250 毫秒更新，准星本身的配色不受此限制。
隐藏准星、设为全透明或不显示任何线条/中心点时暂停取色；空闲检查降至 500 毫秒。
关闭询问功能、默认关闭行为及其他设置都会自动保存。

游戏显示
CS 建议选择「全屏窗口化 / 无边框窗口」。独占全屏可能无法显示桌面叠加层。
这是普通 Windows 桌面叠加窗口，仅识别窗口所属进程名称和 Windows 窗口区域，不读取游戏内存。
居中以画面在屏幕上实际显示的区域为准，不会把内部渲染分辨率直接当作桌面坐标。

已用模拟游戏窗口验证位置、尺寸变化、标题栏排除和最小化等自动居中行为。

源码与构建
源码在「源码」文件夹，C# / Windows Forms，运行需要 Windows 的 .NET Framework 4.8。
本机已具备所需运行环境。
构建：使用 PowerShell 7 执行 源码\build.ps1，或使用 .NET Framework C# 编译器。
源码测试构建支持：桌面准星.exe --self-test（会短暂显示测试窗口，结果写入 test-results.txt）。
发布版已移除内部自检代码。自检会保存并恢复原有设置，请先退出正常运行的实例再执行。
发布构建：源码\build-release.ps1，生成安装程序、便携 ZIP、图标和 SHA256 校验文件。
